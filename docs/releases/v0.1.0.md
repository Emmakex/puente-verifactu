## Integraciones incluidas

La versión soporta el enfoque camaleónico/capability-first para conectar sistemas empresariales sin trasladar autoridad fiscal al origen:

- WooCommerce.
- PrestaShop.
- API HTTP/JSON universal.
- Webhooks.
- CSV/XLSX y carga manual.
- ERP/CRM y software propio mediante API o adaptadores.
- Local Agent para bases de datos, ficheros, SFTP y entornos locales/legacy.

## API universal y starter kits

El candidato exacto superó el contrato API lifecycle v1 y los starter kits HTTP/JSON para:

- Node.js.
- Python.
- PHP.
- curl.

Lifecycle cubierto: `preflight`, `issue`, `status`, `rectify` y `cancel`.

La clasificación fiscal, credenciales AEAT, certificado, transporte y reglas sensibles permanecen server-side en Kairoseth Fiscal.

## Seguridad y operación

- Persistencia productiva Kairoseth: Hostinger + MongoDB.
- Outbox AEAT durable y reconciliación explícita.
- Backup gestionado, cifrado y restore drill validado antes del piloto.
- Rollback `code-first-no-automatic-db-restore`.
- Sin PFX, passphrases, NIF, XML/SOAP crudo ni credenciales MongoDB en Git.
- Evidencias públicas sanitizadas; evidencia privada permanece fuera del repositorio.

## Limitaciones deliberadas de v0.1.0

- `PV_AEAT_ENVIRONMENT=production` no forma parte de esta release operativa.
- `PV_AEAT_ALLOW_PRODUCTION=YES` no debe habilitarse como consecuencia del tag/release.
- No incluye pricing, billing ni checkout comercial.
- No autoriza publicación masiva automática.

## Próximo gate

Tras esta release técnica se realiza distribución controlada e instalación/smoke en los canales soportados. La activación AEAT producción, cuando proceda, requiere un gate independiente, evidencia específica y autorización explícita.
