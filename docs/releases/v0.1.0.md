Release técnica post-piloto para distribución controlada dentro del ecosistema Kairoseth.

- Candidato validado: `fe4c6360a2b25d44f5044e202f7d2bc2faa626a7`.
- Perfil de despliegue: `kairoseth-hostinger-mongodb`.
- Piloto fiscal: **AEAT TEST validado**.
- Resultado piloto: **5/5 operaciones aceptadas**, 1 intento por operación, 0 duplicados, 0 reconciliaciones pendientes y 0 bloqueados.
- Distribución controlada / instalación-smoke: **validada**.
- AEAT producción: **deshabilitada**.

Esta release no equivale a certificación de la AEAT ni autoriza por sí sola activación fiscal en producción.

## Integraciones incluidas

La versión soporta el enfoque camaleónico/capability-first para conectar sistemas empresariales sin trasladar autoridad fiscal al origen:

- WooCommerce.
- PrestaShop.
- API HTTP/JSON universal.
- Webhooks.
- CSV/XLSX y carga manual.
- ERP/CRM y software propio mediante API o adaptadores.
- Local Agent para bases de datos, ficheros, SFTP y entornos locales/legacy.

## API universal y starter kits

El candidato exacto superó el contrato API lifecycle v1 y los starter kits HTTP/JSON para:

- Node.js.
- Python.
- PHP.
- curl.

Lifecycle cubierto: `preflight`, `issue`, `status`, `rectify` y `cancel`.

La clasificación fiscal, credenciales AEAT, certificado, transporte y reglas sensibles permanecen server-side en Kairoseth Fiscal.

## Distribución controlada validada

El CI exacto del candidato instaló y ejecutó smoke real de los canales principales:

- WooCommerce sobre tres combinaciones WP/WC/PHP.
- PrestaShop 1.7.8.11, 8.1.7 y 8.2.7, más upgrade preservando estado.
- Local Agent portable en Linux x64, Windows x64, macOS Intel y macOS ARM64.
- Local Agent read-only contra PostgreSQL, MySQL, MariaDB, SQL Server y SFTP/OpenSSH.
- Onboarding cero-código, mapping, API lifecycle, runtime durable y observabilidad.

La evidencia sanitizada está en `docs/evidence/distribution-smoke-v0.1.0.md` y el procedimiento de instalación/rollback/soporte en `docs/releases/v0.1.0-distribution-runbook.md`.

## Seguridad y operación

- Persistencia productiva Kairoseth: Hostinger + MongoDB.
- Outbox AEAT durable y reconciliación explícita.
- Backup gestionado, cifrado y restore drill validado antes del piloto.
- Rollback `code-first-no-automatic-db-restore`.
- Sin PFX, passphrases, NIF, XML/SOAP crudo ni credenciales MongoDB en Git.
- Evidencias públicas sanitizadas; evidencia privada permanece fuera del repositorio.

## Limitaciones deliberadas de v0.1.0

- `PV_AEAT_ENVIRONMENT=production` no forma parte de esta release operativa.
- `PV_AEAT_ALLOW_PRODUCTION=YES` no debe habilitarse como consecuencia del tag/release.
- No incluye pricing, billing ni checkout comercial.
- No autoriza publicación masiva automática.

## Gate restante

Con documentación, artefactos y distribución controlada validados, queda el gate administrativo/técnico final para crear el tag/release `v0.1.0`. La activación AEAT producción, cuando proceda, seguirá siendo un gate independiente con evidencia específica y autorización explícita.
