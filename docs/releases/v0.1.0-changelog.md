# Changelog v0.1.0

Release técnica inicial de Kairoseth Fiscal / Puente VeriFactu preparada para distribución controlada.

## Núcleo fiscal

- InvoiceIntent y MappingProfile versionados.
- Preflight obligatorio y fail-closed.
- Registros de alta/anulación, huella SHA-256 e idempotencia.
- Encadenamiento fiscal y reconciliación explícita.
- Adaptador AEAT VERI*FACTU con mTLS, control de espera y normalización de respuestas.
- Outbox durable con estados `pending`, `processing`, `completed`, `reconciliation_required` y `blocked`.

## Integración universal

- Universal Integration Kit v1.
- API HTTP/JSON y webhook firmado.
- Starter kits Node.js, Python, PHP y curl.
- CSV/XLSX, mapping assistant y onboarding cero-código.
- Captura manual con preflight.
- Connector Contract Suite v2.

## WooCommerce

- Plugin 0.3.0 reproducible.
- HPOS-safe.
- Facturas y refunds/rectificativas idempotentes.
- Preflight, reconciliación, semáforo operativo y fallback universal.
- Matriz validada: WP 6.5/WC 8.2/PHP 7.4, WP 7.0.4/WC 11.0.1/PHP 8.2 y WP 7.1/WC 11.1/PHP 8.3.

## PrestaShop

- Módulo 0.5.0 reproducible.
- Compatibilidad validada en PrestaShop 1.7.8.11, 8.1.7 y 8.2.7.
- Facturas nativas, abonos/rectificativas, breakdowns fiscales y reconciliación.
- Automatización opt-in por tienda, desactivada por defecto.
- Upgrade con preservación de estado local.

## Local Agent

- Bundle portable 0.1.0 reproducible.
- Lectura read-only de PostgreSQL, MySQL, MariaDB y SQL Server.
- SFTP read-only.
- Smoke nativo en Linux x64, Windows x64, macOS Intel y macOS ARM64.
- `status`/`doctor`, lifecycle de servicio, upgrade y rollback de código.

## Kairoseth Platform

- Perfil productivo Hostinger + MongoDB.
- Registry y stores MongoDB validados.
- Kairoseth Platform fija el motor al commit candidato exacto `fe4c6360a2b25d44f5044e202f7d2bc2faa626a7`.
- Landing pública Kairoseth Fiscal con rutas para WooCommerce, PrestaShop, ERP/CRM, API, Excel/CSV y software legacy.

## Calidad y evidencia

- CI exacto candidato #335 / run `37224109793`: success.
- Piloto AEAT TEST: 5/5 accepted, 1 intento por operación, 0 duplicados, 0 reconciliaciones pendientes y 0 bloqueados.
- Artefactos finales reproducidos con checksums coincidentes.
- Backup cifrado y restore drill validados antes del piloto.
- Evidencia post-piloto y release notes sanitizadas.

## Límites deliberados

- AEAT producción permanece deshabilitada.
- El tag/release no equivale a certificación AEAT.
- No activa pricing, billing ni checkout comercial.
- No autoriza publicación masiva automática.
- La activación fiscal productiva requiere un gate independiente y autorización explícita.
